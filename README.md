# Интерактивная карта прогноза заболеваемости МКБ в Воронежской области на 2026 год

## Описание проекта

Проект представляет собой интерактивную геоинформационную систему для визуализации прогноза заболеваемости мочекаменной болезнью (МКБ) в Воронежской области на 2026 год. Разработан в рамках курсовой работы по дисциплине "Временные ряды" на 3 курсе Воронежского государственного университета (факультет компьютерных наук, кафедра цифровых технологий).

Основная задача — создание наглядного инструмента для медицинского мониторинга, позволяющего оценивать пространственное распределение прогнозной заболеваемости, выявлять территории повышенного риска и анализировать факторы, влияющие на развитие заболевания. Инструмент предназначен для использования региональными органами здравоохранения при планировании распределения медицинских ресурсов, организации профилактических мероприятий и кластеризации зон риска.

## Источники данных

Прогнозные данные сформированы на основе результатов анонимного опроса 800 человек урологического профиля. Анкетирование позволило выявить региональные особенности заболеваемости мочекаменной болезнью, включая географическую привязку случаев, факторы образа жизни и доступность медицинской помощи.

Дополнительно использовались данные о качестве питьевой воды, экологической обстановке и обеспеченности урологической помощью в различных районах Воронежской области. Геопространственные данные (границы муниципальных районов) были получены из открытых картографических источников с последующей ручной верификацией и обработкой.

## Классификация уровней заболеваемости

В основу классификации положены пороговые значения, определенные по результатам анализа опросных данных и медицинской статистики:

| Уровень | Диапазон (на 100 тыс.) | Оценка ситуации |
|---------|----------------------|-----------------|
| Низкий | менее 438,3 | Благополучная — районы с минимальными показателями, требующие поддерживающего мониторинга |
| Средний | 438,3 — 1075,1 | Удовлетворительная — требуется плановая профилактическая работа |
| Высокий | более 1075,1 | Критическая — зоны первоочередного внимания, требующие срочных мер |

## Технологический стек

Проект реализован с использованием языка программирования Python для обработки данных и генерации HTML-страницы. В качестве библиотеки для отображения интерактивной карты применена Leaflet.js, которая обеспечивает удобную навигацию, масштабирование и взаимодействие с пользователем. Геопространственные данные о границах районов используются в формате GeoJSON, полученном из открытых источников OpenStreetMap с последующей верификацией. Интерфейс пользователя построен на HTML и CSS с поддержкой адаптивной верстки.

## Архитектура проекта

Проект построен по принципу клиент-серверного приложения с генерацией статической страницы. Процесс обработки данных и визуализации включает следующие этапы:

| Этап | Компонент | Описание |
|------|-----------|----------|
| 1 | Скрипт generate_map.py | Загрузка прогнозных данных, классификация по уровням, сопоставление с геоданными |
| 2 | Шаблон template.html | Готовый интерфейс с картой, легендой, информационными панелями |
| 3 | Генерация | Подстановка данных в шаблон, создание готового HTML-файла |
| 4 | Визуализация | Отображение интерактивной карты в браузере с полным функционалом |

## Структура проекта

Проект состоит из двух основных файлов:

- **generate_map.py** — скрипт на Python, который обрабатывает прогнозные данные, сопоставляет их с геоданными и генерирует итоговую веб-страницу
- **template.html** — HTML-шаблон, содержащий разметку интерфейса, стили и логику работы карты

Для корректной работы необходим файл с границами районов Воронежской области, загруженный и верифицированный из открытых картографических источников.

## Функциональные возможности

Интерактивная карта обеспечивает следующие возможности для пользователя:

- Визуальное отображение районов с цветовой кодировкой в зависимости от уровня прогнозной заболеваемости (красный — высокий, оранжевый — средний, зеленый — низкий)
- Подсветка района при наведении курсора для удобства навигации
- Получение детальной информации по клику на район: точные прогнозные показатели общей и первичной заболеваемости, данные диспансерного учета
- Отображение вероятных причин высокого уровня заболеваемости для каждого района на основе анализа факторов риска
- Упорядоченный список всех районов с фильтрацией по уровням для быстрого поиска и сравнения
- Автоматическое центрирование карты на выбранном районе при клике в списке

## Результаты прогнозирования

По результатам обработки данных опроса и построения прогнозных моделей, из 32 районов Воронежской области 11 районов (34,4%) отнесены к группе высокого риска с прогнозной заболеваемостью выше 1075,1 случая на 100 тысяч населения. Наиболее критическая ситуация ожидается в Богучарском (2801,8), Павловском (2795,9) и Репьевском (2746,8) районах, где показатели превышают средние значения в 2,5-3 раза. Средний уровень заболеваемости прогнозируется в 18 районах (43,7%), низкий — в 3 районах (21,9%).

Среди благополучных территорий выделяются Бутурлиновский район с показателем 159,0 случая на 100 тысяч населения, Воробьевский (165,3) и Поворинский (299,8) районы, что может служить основой для изучения и распространения успешных практик профилактики.

## Факторы риска

На основе анализа анкетных данных и сопоставления с географическими характеристиками районов выделены ключевые факторы, определяющие высокий уровень заболеваемости:

- **Качество питьевой воды**: высокая минерализация и жесткость воды в Богучарском, Павловском, Репьевском и Каменском районах
- **Доступность специализированной помощи**: отсутствие врачей-урологов и удаленность от областных медицинских центров в Каменском и Нижнедевицком районах
- **Экологические условия**: геологические особенности почвы и промышленные загрязнения

## Практическое применение

Разработанная карта может быть использована в нескольких направлениях:

**Для региональной системы здравоохранения** — позволяет планировать распределение медицинских ресурсов, определяя приоритетные районы для направления врачей-урологов и закупки оборудования; выявлять территории, требующие усиления профилактических мероприятий; отслеживать динамику заболеваемости после внедрения мер.

**В научно-исследовательской деятельности** — служит для визуализации пространственного распределения заболеваемости, выявления кластеров высокого риска и обоснования гипотез о влиянии географических и экологических факторов.

**Для населения** — предоставляет информацию о ситуации в конкретном районе и мотивирует к профилактике в зонах повышенного риска.

## Масштабируемость

Одним из ключевых преимуществ разработанного модуля является его масштабируемость — возможность адаптации для других регионов без изменения программного кода. Для адаптации к новому региону достаточно заменить GeoJSON-файл с границами муниципальных образований, обновить словари с прогнозными значениями заболеваемости и при необходимости скорректировать пороговые значения классификации. Все функции интерактивной карты будут работать автоматически для любого региона с корректными входными данными.

## Выводы

Высокий уровень заболеваемости прогнозируется в 11 районах области, что составляет более трети всех территорий и требует первоочередного внимания со стороны регионального министерства здравоохранения. Наиболее неблагополучными районами признаны Богучарский, Павловский и Репьевский с показателями выше 2700 случаев на 100 тысяч населения.

Основные факторы риска связаны с качеством питьевой воды, доступностью урологической помощи и экологической обстановкой. Созданный инструмент является эффективным решением для визуализации медико-географических данных, позволяет легко обновлять информацию и масштабировать систему на другие регионы, а также дает возможность выявлять пространственные закономерности заболеваемости и принимать обоснованные управленческие решения.
